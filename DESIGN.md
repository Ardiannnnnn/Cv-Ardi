# Portfolio V2

Software engineer portfolio for recruiters and collaborators. Editorial, personal, readable. Reference: Brittany Chiang's content hierarchy and split layout, adapted with Ardian's existing gold accent and portrait.

Dial: ENERGY 2 / RHYTHM 2 / MOTION 1.

- Color: charcoal and gold preserve the existing identity; warm paper provides a readable alternative theme.
- Typography: system sans keeps technical content readable without additional font downloads; serif marks the personal contact invitation.
- Layout: sticky profile anchors identity while content scrolls; mobile follows a single reading order.
- Spacing: generous section spacing separates topics; compact ruled rows make work history scannable.
- Projects: text rows prioritize descriptions and source links; stock photos are not represented as application screenshots.
- Portrait: existing owner-provided photo gives personal context.
- Motif: section numbers connect navigation and content; external arrows indicate repository and resume destinations.
- Motion: hover feedback only; reduced-motion disables transitions.
- Content: personal.json, portofolio.json, experiences.json. No invented metrics or role responsibilities.
